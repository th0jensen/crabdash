## Release Notes
* Added the borderless Crabdash terminal dashboard and Rex command-palette actions, with one pane per section.
* Added responsive System meters, per-core CPU and GPU telemetry, search and filter/sort controls in every section.
* Containers and services expand in place by tap or Tab, with metadata and action/log buttons. Wide panes show actions beside metadata.
* Unix log viewing uses the embedded Bless pager, with ANSI parsing, horizontal panning and search. Windows retains the built-in viewer.
* Updated Ghostty and its Rust bindings to current tips shared by the GUI and Bless, retaining Crabdash's terminal resize and mouse fixes. Builds require Zig 0.17.1.

## Distribution
This version's crates.io publication is gated on compatible registry releases of Bless and its Ghostty bindings. Build `crabdash-tui` from the checkout meanwhile. Merging does not publish crates; only version-tag releases attempt publication.

macOS packages are ad-hoc signed, not notarized. Windows device validation remains pending.
