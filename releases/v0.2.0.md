## Release Notes:
* Crabdash is now available for Linux and Windows, alongside macOS Apple Silicon and Intel builds. The Linux backend supports graphical WSL sessions.
* Added a System dashboard with live CPU and core usage, memory, network, storage, processes, and GPU information.
* Dashboard tabs can be reordered and dragged into splits. Save layouts as workspaces, switch between them, and rename them in place.
* The terminal now supports tabs and splits within its drawer, session names, smooth resizing, scrollback, selection, and clipboard shortcuts.
* Added native macOS controls and Liquid Glass, with independent preferences for Liquid Glass and the system accent. Focused tabs, sidebar selections, and graphs follow the accent.
* Added tray/menu bar integration, Start at login, Start minimised, and single-instance behavior across desktop platforms.
* Refined Docker actions, container removal, run parameters, logs, and Windows Docker discovery.
* Added sortable, filterable tables, distro logos, and a right-click Rename action for machines, including localhost.
* Expanded Preferences with terminal and interface fonts, sizing, terminal compatibility, refresh behavior, and appearance settings.

## Bug Fixes
* Fixed macOS crashes when measuring Unicode labels and disappearing Liquid Glass during tooltips, preferences, and split resizing.
* Fixed terminal autoscroll, text selection, startup cleanup, resizing, and keyboard handling.
* Improved alignment, tab spacing, status-pill contrast, and grouped toolbar actions.
* Error messages remain visible until dismissed or cleared by a successful action.
* Release CI now builds and tests all five platform/architecture combinations, audits the packages, and publishes checksums and dependency notices together.

> [!NOTE]
> macOS builds are ad-hoc signed and are not notarized. On first launch, macOS may block the app. Go to **System Settings → Privacy & Security**, scroll down and click **Open Anyway**.
>
> Windows support is experimental. Native build and automated test coverage does not replace interactive device testing of graphics, tray behavior, and login startup. WSL requires WSLg or another graphical session; tray and login integration depend on the session.
>
> macOS requires 13 or newer; Liquid Glass requires macOS 26. Windows requires Windows 10 version 1809 or newer and Direct3D 11. Linux downloads target Ubuntu 22.04 or newer (glibc 2.35), with Wayland/X11, Vulkan, and the libraries listed in the bundled installation notes.
