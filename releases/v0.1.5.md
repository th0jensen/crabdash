## Release Notes:
* Each dashboard and terminal split now owns its tabs and **+** action. Dashboard menus show only sections missing from that split.
* Focused tabs use the normal foreground colour; inactive tabs are muted without an accent tint.
* Initial system readings appear before optional inventory finishes. Local macOS sampling uses native counters; Windows batches optional probes into one PowerShell session.
* Collapsed log panels release their buffers. Log rendering skips offscreen rows and avoids unused terminal history.

## Bug Fixes
* Fixed Liquid Glass controls disappearing early or distorting at scroll edges.
* Guarded tab actions against stale pane, workspace and machine state; saved pane identities remain stable across layout changes.
* Added Windows executable version metadata and expanded native dependency checks in release CI.

> [!NOTE]
> macOS builds are ad-hoc signed and are not notarized. First launch may require **System Settings → Privacy & Security → Open Anyway**.
>
> Windows support remains experimental. Windows memory improvements were reviewed in code; a measured reduction on Windows has not been verified.
