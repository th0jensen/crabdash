# Machine logos

SVGs from [font-logos](https://github.com/Lukas-W/font-logos) at commit
`d3bf5d299e54595db1b19681a0cc57ab10454857`, distributed under the included Unlicense.
Original vector artwork is unchanged. `windows.svg` is a locally drawn four-pane
Windows mark, distributed under the same Unlicense. Marks identify their respective
operating systems and distributions; trademarks belong to their respective owners.

The application embeds these assets and uses GPUI's SVG renderer, with no runtime
downloads or dependence on an installed icon theme. Machine logo mappings and
presentation live in `features/machines/logos.rs`.
